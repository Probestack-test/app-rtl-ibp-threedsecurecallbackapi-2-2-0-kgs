# threedsecurecallbackapi-2-2-0

Generated Kong declarative configuration bundle.

## Contents

- `kong/kong.yaml`
- `.github/workflows/deploy-dev.yml`
- `apidesign/` — the source OpenAPI specification
- `postman/` — a Postman collection generated from the OpenAPI specification
- `testing/test-cases/` — generated test cases (Postman-shaped collection, a flattened detail file, and a summary)
- `testing/mocks/` — the mock server configured for this resource (Postman "mock" collection, a detail file, and a summary)

The stage folder is intentionally not included yet.
